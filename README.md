## 插件仓库

**[MoviePilot-Plugins](https://github.com/q10710/MoviePilot-Plugins)** · `V2 / V3`

| 插件 | 做什么 |
| :--- | :--- |
| 订阅助手Q自用版 | 订阅全生命周期管理；H&R 种子超时不直接删种，改为收容保种，按站点时长到期再清理 |
| H&R助手Q自用版 | H&R 种子标签与做种时长跟踪，支持多下载器、可识别下载器之间的转移做种 |
| 站点流量管理Q自用版 | 按站点分享率自动管理刷流任务，低于下限启动、高于上限只暂停 |
| 自动限速Q自用版 | 按标签或全局给 qb / tr 的下载任务限速 |
| 做种守卫Q自用版 | 检测无效做种与孤儿源文件，连续达标后按策略处置 |
| 硬链接检查Q自用版 | 清理断开链接的残留文件，并清理媒体库里只剩元数据的空壳目录 |
| 洗版守护Q自用版 | 未完结的误标洗版自动取消；媒体库文件丢失时自动重置订阅重新下载 |
| 过期订阅清理Q自用版 | 订阅长期没新剧集时自动取消 |
| 删档订阅清理Q自用版 | 媒体库条目被删除而订阅仍在时，按配置清理订阅 |

## 快速安装

在 MoviePilot 的 `PLUGIN_MARKET` 中加入：

```
https://github.com/q10710/MoviePilot-Plugins
```

刷新插件市场后搜索插件名安装即可。

## 关注点

- **数据安全优先**：涉及删除文件、删除订阅、改动下载器的插件，开关默认关闭，或只报告不删除
- **口径要写清楚**：每个插件的判据、边界、上游来源都记录在仓库 README 与插件更新说明里
- **可回滚**：改动先自测、再小步发布，保留历史版本说明
